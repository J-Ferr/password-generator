# Password Generator

A clean React + TypeScript password generator that allows users to create customizable passwords with saved preferences, strength feedback, dark mode, and copy-to-clipboard functionality.

## Features

- Generate random passwords
- Choose password length with a slider
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include symbols
- Password strength indicator
- Copy password to clipboard
- Animated copied toast notification
- Dark mode toggle
- Saves user preferences with localStorage
- Responsive card-style UI

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- localStorage
